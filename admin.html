Konfigurasi GitHub Database

Hubungkan ke GitHub

Data tersimpan di repository GitHub, semua pengunjung melihat data yang sama.

Token wajib punya scope repo. Buat di github.com/settings/tokens

Cara Setup:

  1. Buat repository baru di GitHub (bisa private)
  2. Buat Personal Access Token di Settings > Tokens
  3. Centang scope repo (full control)
  4. Isi form di atas, klik Simpan
  5. Klik Cek Koneksi untuk verifikasi
  6. Klik Buat Database kalau file belum ada
  7. Klik Sync Sekarang untuk push data lokal

Catatan: File APK yang diupload hanya tersimpan di localStorage device ini. Data di GitHub hanya menyimpan metadata (versi, link, download count, changelog) agar tidak error 422.
